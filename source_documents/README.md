# source_documents

Diretório raiz para documentos de suporte ao radar de infraestrutura.

Contém subpastas organizadas por origem/confidencialidade dos documentos. Não inclua dados sensíveis neste nível; documentos sensíveis devem ser armazenados apenas em `interno_confidencial`.

Estrutura esperada:

- `mercado/` — documentos públicos e externos usados para o radar de mercado.
- `interno_confidencial/` — documentos internos e confidenciais (acesso restrito).

Siga as regras definidas em `CLAUDE.md` para classificação de fontes e tratamento das informações.
